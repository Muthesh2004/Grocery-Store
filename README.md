# 🛒 Grocery Store Web Application

A full-stack Grocery Store web application that provides users with a convenient platform to browse grocery products, manage their shopping cart, place orders, and track their purchase history.

## 📌 Project Overview

The Grocery Store Web Application is designed to simplify online grocery shopping through a user-friendly interface and an integrated backend. Users can explore products, create accounts, securely log in, add products to their cart, complete checkout, and view their previous orders.

## ✨ Features

* **User Registration:** Create a new account.
* **User Login:** Authenticate and access your account.
* **Product Browsing:** Explore available grocery products.
* **Shopping Cart:** Add products and manage cart items.
* **Checkout:** Proceed through the order placement process.
* **Order Confirmation:** View confirmation after placing an order.
* **Order History:** View previously placed orders.
* **Responsive Interface:** Navigate the application through a user-friendly interface.

## ⚙️ Installation and Setup

### Prerequisites

Install the following before running the application:

* Node.js
* npm
* The database required by your backend, if applicable

### 1. Clone the Repository

```bash
git clone https://github.com/Muthesh2004/Grocery-Store.git
```

### 2. Navigate to the Project Folder

```bash
cd Grocery-Store
```

### 3. Install Frontend Dependencies

```bash
cd client
npm install
```

### 4. Start the Frontend

```bash
npm start
```

The React application will generally run at:

`http://localhost:3000`

### 5. Install Backend Dependencies

Open a separate terminal in the project root and run:

```bash
cd server
npm install
```

### 6. Start the Backend

Check the `server/package.json` file for the available scripts, then start the backend using the appropriate command. For example:

```bash
npm start
```

**Configuration:** Set up the required environment variables and database connection according to your backend configuration before starting the server.
